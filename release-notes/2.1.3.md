### 新增功能

- 桌面宠物支持分别联动 SSH、SFTP 和 AI 活动，并提供连接诊断与测试入口。
- 桌面宠物新增会话消息气泡，可展示任务状态，并单独选择是否展示消息详情。
- 设置新增通用问题反馈入口，可直接前往 GitHub 提交问题。

### 体验改进

- Agent 在可见终端执行命令时展示逐字输入动画，并区分输入中与执行中状态；开启系统减少动态效果后跳过输入动画。
- 设置中的 Petdex 区域更名为“桌面宠物”，方便查找相关选项。
- Windows 构建使用静态 VC 运行库，减少对系统运行库安装的依赖。

### 问题修复

- 修复桌面宠物活动截止时间比较不准确的问题，避免剩余时间变化造成重复状态更新。

### 升级注意事项

- 消息气泡及消息详情默认关闭，需要在桌面宠物设置中手动启用；展示详情前请确认内容适合在桌面显示。
