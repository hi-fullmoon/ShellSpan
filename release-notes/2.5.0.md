### 新增功能

- 连接列表支持同时选择多个标签，显示匹配任一所选标签的连接，并可与分组、收藏、最近使用和搜索条件组合筛选。

### 体验改进

- 优化连接列表的分组与标签筛选控件，长名称自动省略，选中状态更清晰。
- 整理设置页导航、分组标题和操作按钮，将更新选项集中到“软件更新”，改善窄窗口下的显示与滚动体验。

### 问题修复

- 终端重连后保留已结束或空闲的 AI 对话，在确认连接身份一致且没有待执行任务后恢复关联；保留文件与 Skills 的目录边界，并重新要求执行审批，避免重放旧命令。
- 修复关闭已断开或已退出终端时出现的错误，重复或并发关闭同一终端可正常完成。
- 修复 Bash 转交自定义 INT/EXIT 处理器时额外创建前台子进程的问题，保留原有状态码与参数，减少 macOS Bash 3.2 下的进程组竞态。

### 升级注意事项

- 终端重连不会恢复旧连接的进程、环境或执行授权；继续操作前需要检查当前执行状态。
- Bash 信号处理修复适用于新建或重新连接的终端，已运行的终端需重新打开。
- macOS 仍使用 ad-hoc 签名，尚未配置 Developer ID 与公证；Windows 尚未配置发布者证书。本次未进行安装后启动与跨版本升级的实际验收。
