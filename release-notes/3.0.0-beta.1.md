### 新增功能

- **原生终端输入与多平台 Shell 集成**：在 macOS（内置 Bash 5.3 与 Zsh ZLE）、Windows（PowerShell 7）和 Linux x86_64 SSH（glibc 2.28+）启用原生输入协议与可见命令生命周期；绑定终端中的后台命令改为独立进程执行并继承当前工作目录。
- **终端与编辑能力增强**：新增可选 WebGL 渲染开关（异常时自动回退 DOM）、终端自定义配色、分屏缩放与最大化、标签操作菜单、可见命令背景区分，以及 SSH 远程 Vim/Neovim 缓冲区协作编辑与自动附着。
- **Agent 沙箱隔离与网络控制**：新增 macOS 本地 `nono` 沙箱（含可见沙箱终端与违规诊断）、Windows AppContainer 本地沙箱及远端 SSH Bubblewrap 沙箱一键部署；支持按会话开关沙箱、配置域名白名单过滤代理以及将沙箱变更回写到项目工作区。
- **文件检查点与变更回滚**：新增 Agent 文件修改检查点差异预览、跨轮次基线跟踪与安全回滚弹窗，支持在 AI 面板内集中查看本轮全部变更文件并按需展开上下文 Diff。
- **用户 Skills 与远端受限 Sudo**：新增用户自定义 Skills 管理与提议审核界面；新增远端受限 Sudo Runner 机制，可在人工审批后以隔离账号执行提权操作。
- **AI 与 SFTP 工作区增强**：AI 输入框支持 Markdown 编辑与排队消息/图片修改，新增实时上下文压缩进度展示、提问快捷操作与内置模型目录预设；SFTP 新增可配置分屏/标签快捷键、统一语法高亮预览、桌面打开动作及当前 SSH 账号展示。

### 体验改进

- 统一 AI 面板中的工具输入/输出卡片、代码块、只读工具分组与差异折叠展示，优化嵌套滚动、悬停复制和提示条样式。
- 改进子 Agent 任务入口、谱系导航与预算配置，移除主轮次默认步数和累计 Token 上限，支持独立配置请求输出预算。
- 优化终端焦点状态栏、标签拖拽与连接信息复制；远端主机不支持原生输入时自动平滑回退普通 SSH 会话。
- 优化模型提示词缓存、并发读取、终端输出缓冲、前端分包加载与 SSH 原生资源传输性能。

### 问题修复

- 修复流式对话、会话重连、工具审批与子 Agent 调度中的多类状态同步与恢复问题，避免取消、断线或未知执行结果后出现命令重放或授权残留。
- 修复终端原生输入在窗口缩放、全屏程序退出、用户手动接管与控制通道关闭时的显示及恢复异常，防止 SSH 控制通道重复关闭或阻塞。
- 修复 SFTP 并发传输安全性、临时下载隔离、路径面包屑、键盘焦点及切换目录后的滚动重置问题。
- 修复多家 LLM 适配器（Anthropic、OpenAI Responses/Chat Completions、Ollama）在流式工具调用拼接、重试元数据与缓存 Token 统计中的边界问题。

### 安全修复

- 接入内核 `termios` `ECHO` 凭据输入检测并过滤命令输出中的异常控制字符，防止密码提示等敏感输入进入模型上下文；收紧本地与远端临时工作路径隔离。

### 升级注意事项

- 本版本为 `3.0.0` 预发布版本（`v3.0.0-beta.1`），仅供测试者手动下载安装，不会影响稳定版用户的自动更新。
- 已移除旧版终端代码片段（Snippets）功能；Windows 本地原生输入仅支持 PowerShell 7；远端原生输入与临时暂存目录已统一收敛至 `~/.shellspan-server/run`。
- Agent 沙箱隔离与远端受限 Sudo 需在设置中显式启用；macOS 仍使用 ad-hoc 签名（未配置 Developer ID 与公证），Windows 尚未配置发布者证书。
