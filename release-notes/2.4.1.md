### 体验改进

- 终端新增右键菜单，可按需复制、粘贴和清屏；右键点击不再直接粘贴剪贴板内容。
- Terminal 与 Focus 中的 Agent 共用终端占用状态，可跳转到正在使用终端的会话。终端被其他 Agent 占用时阻止新任务提交并保留草稿，释放后可手动重试。
- 优化聊天附件、消息展开操作和终端尺寸提示，统一菜单标签、图标间距与输入区提示的换行和操作位置。

### 问题修复

- 修复消息提交重试与队列准备异常，保留引用的聊天上下文，并避免历史任务影响当前任务。
- 修复后台 Agent 执行终端命令时切走 Focus 工作区的问题；关闭终端会先停止关联 Agent。
- 修复切换 SFTP 面板、连接或目录后传输目标发生变化的问题；传输详情可查看来源与目标路径。
- 移除连接列表的排序控件及已保存的排序行为。

### 升级注意事项

- 终端右键粘贴已改为通过右键菜单执行。
- 本版本仍使用 macOS ad-hoc 签名，尚未配置 Apple 公证或 Windows 发布者证书。
