### 新增功能

- **工作台卡片/表格视图与侧栏面板重构（`beta.4` 新增）**：连接列表、端口转发、快捷操作、Known Hosts 与钥匙串支持持久化卡片/表格视图切换与表格排序；将端口转发与快捷操作升级为工作台独立侧边栏面板并统一卡片交互。
- **Agent 忙碌输入策略持久化（`beta.4` 新增）**：将 Agent 运行中提交偏好（排队或插队引导）收口到 Agent 设置页并持久化保存，保持输入框工具栏简洁。
- **Agent 应用控制面与 `shellspan://` 深链**：新增面向根会话的应用控制工具，支持免密工作区巡检、页面/终端/SFTP 导航、连接与端口转发草稿提议、打开或聚焦终端标签及创建独立对等 AI 会话；新增 `shellspan://` 深链协议，可外部唤起并导航、打开标准认证连接或预填 AI 草稿（绝不自动执行命令或自动提交）。
- **Windows PowerShell 7.4+ 签名准入**：Windows 本地原生输入支持微软 Authenticode 签名的稳定版 PowerShell 7.4+（`< 8.0.0`），同时保留内置 ConPTY / PSReadLine / 原生编辑模块的严格 SHA-256 校验，并在缺失、过旧或不可信时在界面呈现结构化回退原因。
- **SFTP 传输收尾阶段展示**：文件传输进度新增 `finalizing` 收尾阶段状态，准确反映数据写完后的落盘与关闭耗时。
- **原生终端输入与多平台 Shell 集成**：在 macOS（内置 Bash 5.3 与 Zsh ZLE）、Windows（PowerShell 7.4+）和 Linux x86_64 SSH（glibc 2.28+）启用原生输入协议与可见命令生命周期；绑定终端中的后台命令改为独立进程执行并继承当前工作目录。
- **终端与编辑能力增强**：新增可选 WebGL 渲染开关（异常时自动回退 DOM）、终端自定义配色、分屏缩放与最大化、标签操作菜单、可见命令背景区分，以及 SSH 远程 Vim/Neovim 缓冲区协作编辑与自动附着。
- **Agent 沙箱隔离与网络控制**：新增 macOS 本地 `nono` 沙箱（含可见沙箱终端与违规诊断）、Windows AppContainer 本地沙箱及远端 SSH Bubblewrap 沙箱一键部署；支持按会话开关沙箱、配置域名白名单过滤代理以及将沙箱变更回写到项目工作区。
- **文件检查点与变更回滚**：新增 Agent 文件修改检查点差异预览、跨轮次基线跟踪与安全回滚弹窗，支持在 AI 面板内集中查看本轮全部变更文件并按需展开上下文 Diff。
- **用户 Skills 与远端受限 Sudo**：新增用户自定义 Skills 管理与提议审核界面；新增远端受限 Sudo Runner 机制，可在人工审批后以隔离账号执行提权操作。
- **AI 与 SFTP 工作区增强**：AI 输入框支持 Markdown 编辑与排队消息/图片修改，新增实时上下文压缩进度展示、提问快捷操作与内置模型目录预设；SFTP 新增可配置分屏/标签快捷键、统一语法高亮预览、桌面打开动作及当前 SSH 账号展示。

### 体验改进

- **设置页、弹框与交互动画统一（`beta.4` 改进）**：重塑设置页分区、卡片分组、标题模板布局与 Skill 编辑器，统一子弹框与抽屉底部间距并将模型目录操作整合至标题行；优化复制按钮过渡动画、AI 工具标题行内联应用按钮以及面板加载态纵向铺满效果。
- **弹框与配置界面优化**：扁平化 AI Provider 配置弹框并稳定弹框高度；优化连接表单认证选项、沙箱默认配置与 Sudo 策略占位提示；稳定 SFTP 传输进度条布局，避免速率/指标宽度变化引起的抖动。
- **AI 工作区与运行时性能**：复用前端会话 IPC 事件通道、稳定 Store / 草稿 / 控制器生命周期并降低 AI 工作区渲染开销；优化日志流式读取、模型提示词缓存、并发读取、终端输出缓冲、前端分包加载与 SSH 原生资源传输性能。
- 统一 AI 面板中的工具输入/输出卡片、代码块、只读工具分组与差异折叠展示，优化嵌套滚动、悬停复制和提示条样式。
- 改进子 Agent 任务入口、谱系导航与预算配置，移除主轮次默认步数和累计 Token 上限，支持独立配置请求输出预算。
- 优化终端焦点状态栏、标签拖拽与连接信息复制；远端主机不支持原生输入时自动平滑回退普通 SSH 会话。

### 问题修复

- **浅色终端调色板、Petdex 与安装包细节（`beta.4` 修复）**：新增浅色主题 ANSI 调色板与最小对比度保护；修复工作台连接卡片网格缩放与徽章溢出；为 Windows NSIS 安装/卸载程序配置自定义图标；优化 Petdex 退避节奏、工具状态映射、诊断信息与生命周期清理。
- **SSH 原生中继与 SFTP 服务器切换**：将原生 SSH 中继启动延迟至远端 Shell 启动阶段，避免初始化竞争；修复 SFTP 切换服务器时未重置当前目录及误应用过期目录列表的问题。
- **Agent 运行时并发、Windows 沙箱与工作台界面**：修复驱动循环、子 Agent、临时脚本目录与产物存储中的并发竞态，改进上下文压缩预算计算、子进程回收与直接执行场景上下文及工具 Schema 说明；修复 Windows 下沙箱变更应用与丢弃时的嵌套相对路径分隔符问题及工作台标题栏帮助图标对齐问题。
- 修复流式对话、会话重连、工具审批与子 Agent 调度中的多类状态同步与恢复问题，避免取消、断线或未知执行结果后出现命令重放或授权残留。
- 修复终端原生输入在窗口缩放、全屏程序退出、用户手动接管与控制通道关闭时的显示及恢复异常，防止 SSH 控制通道重复关闭或阻塞。
- 修复 SFTP 并发传输安全性、临时下载隔离、路径面包屑、键盘焦点及切换目录后的滚动重置问题。
- 修复多家 LLM 适配器（Anthropic、OpenAI Responses/Chat Completions、Ollama）在流式工具调用拼接、重试元数据与缓存 Token 统计中的边界问题。

### 安全修复

- **Agent 安全边界加固**：加固 Shell 命令守卫、MCP stdio 隔离与 Schema 边界校验、沙箱代理 SSRF/HTTP 校验、作用域受限文件读取及凭据脱敏规则；`shellspan://` 深链与应用控制草稿均强制执行敏感凭据拦截。
- 接入内核 `termios` `ECHO` 凭据输入检测并过滤命令输出中的异常控制字符，防止密码提示等敏感输入进入模型上下文；收紧本地与远端临时工作路径隔离。

### 升级注意事项

- 本版本为 `3.0.0` 预发布版本（`v3.0.0-beta.4`），仅供测试者手动下载安装，不会影响稳定版用户的自动更新。
- 已移除旧版终端代码片段（Snippets）功能；Windows 本地原生输入要求微软签名的 PowerShell 7.4+（`< 8.0.0` 稳定版）；远端原生输入与临时暂存目录已统一收敛至 `~/.shellspan-server/run`。
- Agent 沙箱隔离与远端受限 Sudo 需在设置中显式启用；macOS 仍使用 ad-hoc 签名（未配置 Developer ID 与公证），Windows 尚未配置发布者证书。
