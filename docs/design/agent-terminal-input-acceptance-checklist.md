## 执行约定

- 当前只允许编译、类型和静态检查。App、浏览器、模型、Shell/PTY/SSH运行验收须在用户明确安排后进行，集中使用验收窗口，避免反复启动开发应用打断前台工作。
- 原生App串行运行。只有已安排的前台验收命令可临时设置`SHELLSPAN_ALLOW_FOREGROUND_TESTS=1`，不写入默认脚本或用户配置。入口缺少门禁也不代表得到运行授权。
- 使用真实Shell、PTY、私有控制通道、SSH及浏览器，不使用mock、不合成生命周期或证明，不改写原始捕获。普通输出、OSC、屏幕文字和前端ready均不能作为执行授权证据。
- 只在本地独立验收目录或明确授权的受控测试环境创建无业务数据的验收产物。不对业务主机做有副作用的验收；不修改真实用户配置、执行权限、审批、冻结目标或无关UI。
- 凭据只使用系统钥匙串或CredentialRef。证据保留非秘密身份和摘要，不记录密码、私钥、token、私有控制端点或审批凭据。
- 不明结果、断线、中断、零个匹配测试、跳过用例及缺少环境均不能记为通过；不得自动重放可能已提交的操作。
- 不提交、不推送、不发布；生产准入另行明确决定。

状态统一使用：待验、通过、失败、阻塞、不适用。只有达到通过标准且登记证据才勾选；不适用须写明理由，不能缩小必需平台范围。

每个编号均须有记录；涉及多平台的项目按“编号×平台×Shell×传输×浏览器/渲染器”逐项展开，不只勾选父项。

### 源码与制品

- [ ] A01 冻结完整工作区、协议和依赖；当前资源重新构建，不复用旧命名制品作为当前证明。
- [ ] A02 `pnpm build`、主程序`cargo check --locked --manifest-path src-tauri/Cargo.toml --tests`、两个原生库编译、Rust引入文件格式、终端边界及`git diff --check`通过。已有日志只作前次静态检查记录，冻结批次须记录相应命令及退出码。
- [ ] A03 核对协议、显示键、builtin、只读提示符列符号、资源路径、catalogue、打包和加载器一致；未知构建、错误摘要、错误平台及缺失符号均拒绝能力。
- [ ] A04 运行实验配置隔离回归；实验配置不能进入生产清单、获得正式输出捕获或后台作业能力。
- [ ] A05 检查实际测试清单及过滤器，匹配数量非零；记录选中、通过、失败、跳过数量。聚合入口须先核对依赖、用例与执行范围，不能以聚合退出码掩盖空测或漏测。
- [ ] A06 从随包源码及固定依赖重建；校验模块、relay、Core、资源映射和来源清单，实际运行加载的是本批次制品。

### 原生行内输入与执行语义

- [ ] B01 单行、多行、长源码、Tab/CR/LF、引号、heredoc、字面量`!`、中文、组合字符及emoji输入完整；实际编辑缓冲、游标、UTF-8字节长度与证明一致。
- [ ] B02 原生逐步输入可见且连续，无包装泄露、重复源码、缺尾、覆盖或闪屏；准备与输入阶段均不能提交。减弱动画配置仍保持原生行内体验。
- [ ] B03 源码、计划、审批、目标及完整身份不可变；不完整证明、错误身份、过期、撤销、代次改变或清单不匹配时拒绝接受键。
- [ ] B04 父Shell执行语义正确：工作目录、变量、函数、退出状态、启动文件、prompt及历史选项；PowerShell覆盖using、param默认表达式/校验、命名block及正文前失败。不改真实用户配置。
- [ ] B05 语法错误或不支持输入在执行前拒绝，前置命令无副作用；取消后下一次用户Enter不能执行残留草稿。
- [ ] B06 后台启动、输出、轮询、停止、退出状态及不透明handle身份一致；管理命令不变成可见历史源码。原生接受、Started、Settled和输出尾部捕获分别验证。
- [ ] B07 默认、小、自定义、空、未设置历史配置分别验收；原生应用Bash矩阵为当前脚本列出的39项，记录实际完整选择清单。子集通过不算完整矩阵通过。

### 唯一提交、停止与恢复

- [ ] C01 顺序证明为完整输入→FULL持久意图→重新准入→武装确认→单次可能提交；重复commit、重复调用及并发输入不增加可执行提交。
- [ ] C02 输入中、完整输入后、持久意图后、武装后、接受前后、运行中分别停止/取消/接管，确认实际清稿或真实执行事实；未确认清理时不归还编辑权。
- [ ] C03 人工输入与Agent争用、多Agent并发、委派、任务切换、关闭运行终端：保持所有权、确认、权限和其他任务不受影响。
- [ ] C04 真实进程崩溃及重启验证：意图已落盘仍阻止重新输入/接受；存储丢失、只读、不可用、未知格式及其他账本命名空间拒绝新提交，不建立空账本绕过记录。
- [ ] C05 控制通道EOF、SSH断线、超时和接受结果不明时保持恢复门禁；不明操作保留协调器和捕获，迟到Started只补事实，匹配Settled才能结算。
- [ ] C06 私有报文拆包、合包、超长、非法JSON/UTF-8、EOF半帧、乱序、重复、冲突身份及旧代次均符合协议；查询不耗尽取消能力、不重置期限、不生成输入或结束证明。
- [ ] C07 单独核对持久化崩溃探针与原生端到端崩溃证据；独立账本探针通过不能代替真实prepare/proof/intent/arm/key链路。

### 显示、复制和浏览器

- [ ] D01 使用新采集的真实PTY流，在Chromium/WebKit及DOM/WebGL分别检查；不支持组合明确列为阻塞或排除边界，不填通过。原生WebView独立验收。
- [ ] D02 动态改变宽高、窄宽切换、长行、宽字符、后台输出穿插；源码与普通输出完整，无覆盖、光标漂移或重复重画。
- [ ] D03 正反向鼠标选择、软/硬换行复制、空格/Tab/Unicode、搜索及历史输出正确；同时覆盖默认显示模式，核验通用xterm补丁影响范围。
- [ ] D04 历史视口停留与底部跟随分别验证；横向重排保持有效选择锚点及视口，不搜索原文回选、不重放历史。
- [ ] D05 模式进入/退出与真实PTY同序；重复enter、外部provider切换、取消、EOF和销毁恢复显示基线；OSC不能授予输入、结束或执行权。
- [ ] D06 native→native→raw→native重绑、半OSC/UTF-8、旧尾包与新连接输出有序排空；不清屏、不reset私有parser、不让旧控制器影响后继。

### 平台与应用收口

- [ ] E01 受控SSH上传及读取校验、独立relay、终端尺寸、信号、生命周期和断线均通过；远端无授权目录之外的写入。
- [ ] E02 ZLE同线程编辑/计时/清稿、父解析器交接、hook/widget归属、信号及启动文件恢复正确；EOF不自动执行或伪造DraftCleared。
- [ ] E03 两个PowerShell分别核验实际程序集、编辑器线程、UTF-16到UTF-8边界、命名管道DACL/PID/句柄继承及ConsoleHost顶层执行；不修改系统信任或执行策略。
- [ ] E04 普通终端手工编辑、TUI及raw拒绝路径正确；保留审批、冻结目标和取消语义；只读状态不改变后端准入，无关UI不变。
- [ ] E05 被动记录前台应用/窗口/PID与时间线，定位已记录的失焦现象；不强制抢回焦点，不用另一轮成功覆盖失败。验收进程不得在安排时段外自行启动App。
- [ ] E06 实际模型驱动Agent完整调用链与无模型原生测试分别记录；模型请求失败不算终端通过，也不重放不明调用。
- [ ] E07 通过正常API核对并清理测试临时CredentialRef及本批次资源，验证清理结果；不导出秘密或直接改写共享vault。只关闭/清理已确认归本批次所有的进程、容器、目录和端口。
- [ ] E08 完成相关回归和完整质量门禁；汇总平台、必测用例及失败处置后，明确生产配置准入结论。未通过项保留关闭，不自动发布。
