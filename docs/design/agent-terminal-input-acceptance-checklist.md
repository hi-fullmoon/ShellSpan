## 执行入口与顺序

以下为当前运行索引。用户已安排的Windows前台时段覆盖独立诊断App、Shell和浏览器，不再沿用早期“仅静态”的限制。A04属于运行回归，A06依赖已构建资源，不是所有独立诊断的静态前置。任一必需前置失败，停止依赖它的下一层；独立诊断仍可单列，但不能据此越过正式路径门禁。

## 可核对的通过标准

| 观察 | 通过要求 |
| --- | --- |
