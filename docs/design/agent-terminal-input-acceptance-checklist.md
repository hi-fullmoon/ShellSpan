## 验收范围

A01–A06、B01–B08、C01–C07、D01–D06、E01–E08 共 35 个要求。按五个发布绑定登记 175 条待审义务，再逐项判断适用性并展开正向、负向、故障、显示及人工子案。Bash 4.1／4.4 的兼容验证按需单列，历史批次保留原绑定及统计。

| 平台与传输 | 绑定 |
| --- | --- |
| macOS arm64，本地 PTY | Bash/Readline 5.3/8.3.6 |
| macOS arm64，本地 PTY | 私有 Zsh 5.9/ZLE 5.9，绑定对应 Core/Main |
| Linux aarch64、glibc 2.36，受控 SSH PTY | Bash/Readline 5.3/8.3.6 |
| Linux aarch64、glibc 2.36，受控 SSH PTY | 私有 Zsh 5.9/ZLE 5.9，绑定对应 Core/Main |
| Windows x64，ConPTY 1.25.260930003 | PowerShell 7.6.9/private PSReadLine 2.4.5-shellspan6 |

Shell、编辑器、Core、模块及 relay 均按实际版本和 SHA-256 绑定；版本变化须更新对应批次，不能移动旧证据范围。不支持的 Shell、架构、libc 或未校验模块须验证普通 raw 终端与 Agent 拒绝路径，不能登记为原生能力通过。Windows 经 SSH 执行只能证明相应远端组合，不替代 Windows 本地 App/ConPTY。

## 状态与证据规则

| 状态 | 使用条件 |
| --- | --- |
| 未执行/待验 | 尚未运行，或现有证据不足以覆盖完整要求 |
| 通过 | 对应冻结、平台、子案及必需证据全部匹配 |
| 失败 | 实际断言或必需门槛未通过，保留原结果与诊断 |
| 阻塞 | 所需环境、制品或外部条件不可用，注明具体原因 |
| 不适用 | 依据适用范围逐项说明理由，不作为通过计数 |

编译、组件、无模型原生、实际 App、实际模型、浏览器与人工结果分别记录。跳过、忽略、未执行、未知及失败不能算通过。旧代码通过不直接继承到更新后的代码；提交号、截图、聚合退出码和非零测试数量均不能单独证明完成。

## 不变约束

1. 生产编辑器准入以 [固定配置清单](../../protocol/agent/runtime/native-editor-admission.json) 为准；各平台实机验收与发布仍按各自的流程和证据记录。
2. 保持权限、审批、冻结目标、取消与恢复围栏；不额外解析或修补模型参数，不缩减原测试条件，不回退 Direct。
3. 结果不明的操作不重放；新复验须使用新身份、独立目录和新批次，旧失败、未知账本及原制品不改成通过。
4. 真实清稿/结束事实才能归还输入权或结算原意图；OSC、显示文本和数值退出码不能伪造输入或执行证明。
5. 只处理已确认属于本批次的进程、目录、端口和凭据，沿用正常 API 与系统回收站，不直接修改共享 vault；秘密不得进入日志、源码或普通快照。
6. 运行沿用会话中已明确的授权范围与时段，暂停不因文档修改自动解除。不得在安排外自行启动 App，不为焦点异常自动抢回前台。已有授权不因重写文档重新失效。

## 必需检查项目

以下 35 条用于逐平台复核子案。自动化工具读取本文中的编号和要求，实际结果登记在批次台账中。

### 源码与制品

- [ ] A01 冻结完整工作区、协议和依赖，列明待重建资源及其构建目标；核对测试、配置及证据使用`artifacts/`规定子目录。实际重建在后续资源核验阶段完成，不复用旧命名制品作为当前证明。
- [ ] A02 `pnpm build`、主程序`cargo check --locked --manifest-path src-tauri/Cargo.toml --tests`、两个原生库编译、`pnpm check:rust:includes`、`pnpm check:terminal:boundary`及`git diff --check`通过。每个原生库分别执行`cargo check --locked --manifest-path <该库目录>/Cargo.toml --all-targets`，记录实际平台及未覆盖目标。已有日志只作前次静态检查记录，冻结批次须记录相应命令及退出码。
- [ ] A03 核对协议、显示键、builtin、只读提示符列符号、资源路径、catalogue、打包和加载器一致；未知构建、错误摘要、错误平台及缺失符号均拒绝能力。
- [ ] A04 运行实验配置隔离回归；实验配置不能进入生产清单、获得正式输出捕获或后台作业能力。
- [ ] A05 检查实际测试清单及过滤器，匹配数量非零，且选中清单覆盖预先固定的必测项；记录选中、执行、通过、失败、跳过数量。核验`artifacts/`内复制的源码、测试和嵌套快照不进入普通测试发现或源码清单，快照索引仍只读且有效。聚合入口须先核对依赖、用例与执行范围，不能以聚合退出码掩盖空测或漏测；非零数量本身也不证明覆盖完整。
- [ ] A06 从随包源码及固定依赖重建；校验模块、relay、Core、资源映射和来源清单，实际运行加载的是本批次制品。

### 原生输入与执行

- [ ] B01 单行、多行、长源码、Tab/CR/LF、引号、heredoc、字面量`!`、中文、组合字符及emoji输入完整；实际编辑缓冲、游标、UTF-8字节长度与证明一致。覆盖8192字节源码边界及超限拒绝；禁止的控制字符、空源码和非法编码不得进入输入。
- [ ] B02 原生逐步输入可见且连续，无包装泄露、重复源码、缺尾、覆盖或闪屏；准备与输入阶段均不能提交。减弱动画配置仍保持原生行内体验。
- [ ] B03 源码、计划、审批、目标及完整身份不可变；不完整证明、错误身份、过期、撤销、代次改变或清单不匹配时拒绝接受键。
- [ ] B04 父Shell执行语义正确：工作目录、变量、函数、退出状态、启动文件、prompt及历史选项；PowerShell覆盖using、param默认表达式/校验、命名block及正文前失败。不改真实用户配置。
- [ ] B05 语法错误或不支持输入在执行前拒绝，前置命令无副作用；取消后下一次用户Enter不能执行残留草稿。
- [ ] B06 后台启动、输出、轮询、停止、退出状态及不透明handle身份一致；管理命令不变成可见历史源码。原生接受、Started、Settled和输出尾部捕获分别验证。
- [ ] B07 分别验收默认、小、自定义、空、未设置历史配置。Bash 5.3 发布矩阵含本地 6 项与 SSH 7 项，记录实际选择清单并逐项核对。
- [ ] B08 通过真实文件工具创建并读回临时脚本，在原生终端执行返回的绝对路径，保持冻结目标、原cwd、父Shell环境及审批语义，不回退Direct。核对本地`{dataRoot}/tmp/{shortId}`的16位目录与完整所有权记录、重启复用、占用/归属冲突及符号链接拒绝；脚本在批准后才写入，拒绝时不覆盖既有文件。原生命令及证明绑定实际路径调用，不把路径调用显示冒充完整脚本文本显示。运行、后台或结果不明时文件保留引用；仅确认终止后按既有规则清理，关闭聊天不证明终止。Direct对照与受控远端SFTP结果单列，不替代原生链路。

### 唯一提交、停止与恢复

- [ ] C01 顺序证明为完整输入→FULL持久意图→重新准入→武装确认→单次可能提交；重复commit、重复调用及并发输入不增加可执行提交。
- [ ] C02 输入中、完整输入后、持久意图后、武装后、接受前后、运行中分别停止/取消/接管，确认实际清稿或真实执行事实；未确认清理时不归还编辑权。
- [ ] C03 人工输入与Agent争用、多Agent并发、委派、任务切换、关闭运行终端：保持所有权、确认、权限和其他任务不受影响。
- [ ] C04 真实进程崩溃及重启验证：意图已落盘仍阻止重新输入/接受；已初始化存储丢失、只读、不可用、未知格式、符号链接及其他账本命名空间拒绝新提交，不建立空账本绕过记录。全新独立目录允许首次初始化；Unix账本目录0700、数据库0600；实际校验存储及重复调用围栏。
- [ ] C05 控制通道EOF、SSH断线、超时和接受结果不明时保持恢复门禁；不明操作保留协调器和捕获，迟到Started只补事实，匹配Settled才能结算。
- [ ] C06 私有报文拆包、合包、超长、非法JSON/UTF-8、EOF半帧、乱序、重复、冲突身份及旧代次均符合协议；查询不耗尽取消能力、不重置期限、不生成输入或结束证明。
- [ ] C07 单独核对持久化崩溃探针与原生端到端崩溃证据；独立账本探针通过不能代替真实prepare/proof/intent/arm/key链路。

### 显示、选择与浏览器

- [ ] D01 使用新采集的真实PTY流，在Chromium/WebKit及DOM/WebGL分别检查；不支持组合明确列为阻塞或排除边界，不填通过。原生WebView独立验收。
- [ ] D02 动态改变宽高、窄宽切换、长行、宽字符、后台输出穿插；源码与普通输出完整，无覆盖、光标漂移或重复重画。
- [ ] D03 正反向鼠标选择、软/硬换行复制、空格/Tab/Unicode、搜索及历史输出正确；同时覆盖默认显示模式，核验通用xterm补丁影响范围。
- [ ] D04 历史视口停留与底部跟随分别验证；横向重排保持有效选择锚点及视口，不搜索原文回选、不重放历史。
- [ ] D05 模式进入/退出与真实PTY同序；重复enter、外部provider切换、取消、EOF和销毁恢复显示基线；OSC不能授予输入、结束或执行权。
- [ ] D06 native→native→raw→native重绑、半OSC/UTF-8、旧尾包与新连接输出有序排空；不清屏、不reset私有parser、不让旧控制器影响后继。

### 平台、应用与收口

- [ ] E01 受控SSH上传及读取校验、独立relay、终端尺寸、信号、生命周期和断线均通过；远端无授权目录之外的写入。复用冻结的用户终端，不额外创建终端标签；原生宽窄窗口验证状态展示、租约/接管及断线重连。
- [ ] E02 ZLE同线程编辑/计时/清稿、父解析器交接、hook/widget归属、信号及启动文件恢复正确；EOF不自动执行或伪造DraftCleared。
- [ ] E03 在 PowerShell 7 核验实际程序集、编辑器线程、UTF-16 到 UTF-8 边界、命名管道 DACL/PID/句柄继承及 ConsoleHost 顶层执行，沿用系统信任与执行策略。覆盖默认选中已匹配的 `pwsh.exe`、缺少匹配版本时使用普通终端，以及明确指定 Shell 时尊重该选择。
- [ ] E04 普通终端手工编辑、TUI及raw拒绝路径正确；保留审批、冻结目标和取消语义；只读状态不改变后端准入，无关UI不变。
- [ ] E05 被动记录前台应用/窗口/PID与时间线，定位已记录的失焦现象；不强制抢回焦点，不用另一轮成功覆盖失败。验收进程不得在安排时段外自行启动App。
- [ ] E06 实际模型驱动Agent完整调用链与无模型原生测试分别记录；模型请求失败不算终端通过，也不重放不明调用。
- [ ] E07 通过正常API核对并清理测试临时CredentialRef及本批次资源，验证清理结果；不导出秘密或直接改写共享vault。只关闭/清理已确认归本批次所有的进程、容器、目录和端口。
- [ ] E08 完成相关回归和完整质量门禁；独立核对历史 scoped loopback HTTP/SSH 转发超时项，终端专项通过不能替代完整 SSH 门禁。汇总平台、必测用例及失败处置后，明确生产配置准入结论。未通过项保留关闭，不自动发布。

## 执行门槛

| 顺序 | 前置与产出 |
| --- | --- |
| 1. 冻结与预检 | 记录完整源码、工作区差异、锁文件、工具链、配置及只读索引；完成对应 A01/A02 和 A03/A05 审查 |
| 2. 重建与资源 | 核对固定上游输入，隔离重建并验证正确/错误资源准入；包内源码重建与实际加载分别证明 A03/A06 |
| 3. 组件与显示 | 执行对应组件、协议及浏览器回归；必需前置失败即停止其依赖项，独立诊断单列 |
| 4. App 与模型 | 使用绑定本批制品的应用包；逐平台验证工具链、争用、故障、恢复、显示及人工子案 |
| 5. 清理与审计 | 失败也执行安全可行的本批清理；核对所有必需子案和原始证据，再给出限定范围结论 |

同一兼容制品可按工具契约复用，但必须核对原制品、控制器、依赖、资源、CSP、端口及安装路径；运行中、终止不明、输入不匹配或封存漂移时拒绝复用。复用旧制品不等于重新编译，更不恢复旧会话或操作。

原生 App 串行执行；发现其他批次活动驱动时停止本批安排，不结束其他进程。进程须绑定 PID、绝对可执行路径及创建时刻或原阶段起止时刻，不能用 PID 复用推断原进程仍存活或已退出。停止、期限及取消参数按运行前记录执行，不以等待延长掩盖未知。

## 冻结与单案记录

所有新产物放入根目录 `artifacts/tests/<专项>/<批次>/`。固定输出入口在独立源码副本运行，保留实际输出映射，不覆盖旧批次。Git 忽略不等于运行输入可省略：资源、制品、前端资产、工具和只读快照索引分别登记摘要，运行前后核对；漂移则保留原结果并新建批次。

每案至少记录：

- 要求 ID、阶段、子案、适用平台/传输/Shell 与排除理由。
- 实际 HEAD、源码及差异摘要、依赖锁、工具链、命令/参数、退出码和用例发现/执行/跳过清单。
- 应用包、模块/编辑器/Core/relay、浏览器/渲染器及实际加载对象的路径、版本、摘要与来源。
- 独立身份、数据/HOME/WebView 目录、进程身份、端口/资源所有权、审批和运行前固定期限。
- 原始/准备源码是否逐字一致、UTF-8 长度、接受次数、实际效果、Started/Settled/清稿及恢复状态；无法证明则记未知，不用业务秘密填充证据。
- 原始捕获、完整性摘要、截图/录像、脱敏日志、失败处置、复验关系及正常 API 清理结果。

成功案要求恰好一次接受及预定效果；拒绝、准备及提交前取消为零。不明案保持未知与恢复门禁。显示检查要保存完整字节/逻辑文本、选择、视口、窗口尺寸和时间线；截图不能代替协议证明，也不能用补写源码、搜索回选或重放历史修复画面。
