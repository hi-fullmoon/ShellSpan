# Agent Shell 沙箱剩余问题

核对日期：2026-10-07。依据当前源码与阶段 3、4、5 验收记录；本次整理未重跑真实模型、SSH 或平台验收。

macOS 本地及普通账户直接 SSH 已接入 Seatbelt Direct，逐目标预检成功后报告 `partial`。本地文件读取、缓存读写、指定公网 TCP 代理、Node 本地服务授权，策略切换、配置记忆、审计和指定关闭／跨进程恢复场景已有实现与对应证据。整体发布验收仍未完成。

## 尚需开发

1. **可信运行期越界诊断。** 当前可按明确资源请求审批，但没有完整的控制器证据驱动诊断与权限扩展建议。普通 stderr、非零退出及模型解释不能作为扩权依据；状态不确定的命令不能自动重放。
2. **Windows 受限执行后端。** 当前本地生产限制依赖 macOS Seatbelt；Windows 需按相同常规沙箱契约落实文件、网络、进程和授权控制，并在用户提供的实机上验证，不能仅补测试便宣称支持。

## 尚需完成验收

3. **远端异常生命周期。** 长期断网、应用强制崩溃、远端残留／临时资源、恢复清理及多远端会话并发仍缺完整证据；不可确认的清理须保持 uncertain 并暂停派发。
4. **完整主工作台组合。** 补齐首次远端目录选择、目标变化后的过期验证结果清理、策略／审批／能力摘要一致性、恢复和子 Agent／fleet／队列入口，以及完整 Wry 审批审计 IO 故障验收。已有独立组件和模型场景不能覆盖全部组合。
5. **真实 SSH 部署业务链。** 需在自有普通账户 fixture 上完成实际产物上传、哈希校验、启动、健康／版本读取、更新和所属资源清理；现有 SSH 命令与文件测试不足以证明部署完成。
6. **网络与工具边界汇总。** 默认拒绝、指定代理和服务已有真实子项证据；仍需按声明支持范围汇总地址族、客户端、子进程，以及结构化文件、HTTP、SFTP、部署、MCP 的独立入口门禁，避免把单项通过外推到所有入口。
7. **最终质量与发布门禁。** 阶段 5 最后记录为前端 2581 passed／2 skipped、Rust 1228 passed／76 ignored 与另 5 项集成通过、build 通过；这些是历史对应修订的结果。`cargo fmt --check` 记录仍未通过，需处理相关差异并完成匹配最终修订的检查、平台支持说明和回退验收。忽略项不能计作通过。

## 首版限制与尚未开放的范围

- 硬链接别名、同账户恶意并发修改和敌对后代逃离进程组属于已接受且必须披露的 `partial` 限制；完整对象隔离、Endpoint Security 服务与 Linux 桌面迁移不是首版前置条件。
- 远端资源扩展授权、root、受限跳板双跳、其他远端受限后端尚未开放；如后续要求支持，应另行实施并验收。
- 普通可视终端不受 Shell 沙箱隔离；受限执行使用 Direct。MCP、SFTP 和部署等工具只开放已接入的能力，不能借宿主工具替代受限 Shell。
