## 2. 产品范围与策略

桌面目标为 macOS 和 Windows；不新增 Linux 桌面产品模式。SSH 的实际执行系统独立判断。首版采用常规原生进程沙箱，不承诺完整文件对象隔离，不引入 Endpoint Security 服务、特殊磁盘权限、自研内核驱动或 Linux 桌面迁移作为前置条件。

审批模式决定是否执行，执行策略决定批准后的资源范围，二者独立。

| 策略 | 文件与网络语义 | 默认用途 |
| --- | --- | --- |
| `readOnly`／只读检查 | 保护项目和主机文件不被修改；允许必要系统运行文件及最小专属临时写入；网络默认拒绝 | 阅读代码、日志和诊断 |
| `workspace`／工作区执行 | 冻结项目可读写，专属临时资源可写；缓存、文件读取和网络按已支持的精确授权扩展 | 修改、构建、测试及开发服务 |
| `host`／主机运维 | 使用目标账户原有权限，无文件／网络隔离；不自动授予 sudo，也不扩大结构化工具契约 | SSH 运维及部署 |

新建本地项目会话默认工作区策略，缺少有效目录时先选择目录；新建远端会话默认 Host。历史策略不静默转换。选择完全访问不修改审批模式。受限会话使用 Direct，不能把命令注入用户已有普通可视终端。

仅在目标后端验证成功后开放受限派发。`sandboxCapability` 的 `files`、`network`、`processLifecycle` 分别报告事实：macOS 当前为 `partial / files=true / network=true / processLifecycle=false`。文件字段表示路径限制，生命周期字段不否定已有普通进程组取消能力，也不代表完整敌对后代控制。预检失败、缺组件或必要控制缺失均拒绝，不自动回退 Host。

## 3. 安全、授权与恢复契约

### 3.1 文件和凭据

- 根目录在实际执行主机规范化，按调用冻结身份、策略、读写允许和拒绝集合。拒绝范围优先；系统及选定工具链只读，缓存不开放整个 HOME。
- 私钥、系统／应用钥匙串、ShellSpan 存储及已识别敏感路径默认拒绝。冻结项目根 `.env.local` 是基础只读例外，不能覆盖独立秘密规则，不能写入。
- 清理继承环境，不 source 用户登录配置；模型和 SSH 凭据留在应用／连接层，不注入 Shell。需要秘密的工具沿用明确授权的代理或 credential reference。
- 结构化文件工具、HTTP、SFTP、部署及 MCP 各自执行入口门禁，不继承 Shell 隔离；未接入的受限入口拒绝。用户直接操作既有页面不因此被宣称为沙箱操作。
- 硬链接别名、宿主同账户恶意并发修改及敌对后代逃离进程组是必须披露的 macOS `partial` 限制，不重复运行已被中止的危险反例，不用路径扫描宣称对象隔离。

### 3.2 资源授权与网络

本地已接入项目／非敏感外部普通文件读取、明确账户缓存子目录读写、指定公网 TCP 代理及 Node 回环服务。读取和写入请求均最多 8 个受支持对象；精确类型、路径校验及拒绝规则以[沙箱协议](../../protocol/agent/runtime/sandbox-policy.md)为准。远端资源扩展、网络目标和本地服务 grant 仍不支持。

初次资源扩展必须显式批准，提供本次执行（默认）或当前会话；一次审批可同时批准操作和新资源。有效会话资源可以复用，但操作审批仍独立，不延长原期限。会话授权只在内存中，最长一小时；派发时核对 Session、call、target、绑定版本、期限、撤销及原生签名。配置记忆只保存策略和目录候选，不保存授权。

macOS 默认 `network* deny` 约束 Shell 及子进程。公网 TCP 通过受控 Unix 代理，不能绕过代理直连；TCP host/port 不等于 HTTPS 内容、URL 路径或重定向验证。Node 本地服务授权限定回环地址、端口及已接入 relay，允许监听不等于任意外连。IPv4／IPv6、DNS、Unix socket、SSH forwarding 和其他客户端的完整支持范围仍须按矩阵验收，不能把一次 curl 或下载成功外推为全网络控制。

只有控制器可信事实可以支持越界诊断。普通 stderr、EPERM、非零退出和模型解释不能自动诱发扩权；已执行或状态不确定的命令不自动重放。

### 3.3 绑定、撤销与资源归属

冻结调用绑定 Session 创建时间、`bindingRevision`、策略、执行方式、完整目标、账户／认证、连接代际和规范化根。远端另绑定数据库掌管的配置 nonce、实际 SSH 主机密钥和 backend stamp；修改后切回原值、同身份重连或重新预检均不能恢复旧审批。固定 peer 在认证前核对，不把凭据发送给变化后的主机。

策略切换要求会话空闲且无受影响的审批、队列、子会话、后台资源或终端租约。撤销授权先停止相关派发并确认所属进程停止；审计写入失败同样停止执行，清理失败继续保留。子 Agent／fleet 不得扩大父权限，不继承临时资源扩展。

派发前保存非授权性意图；受保护清理 capsule 托管在系统钥匙串，普通状态只存引用。恢复仅凭精确归属和签名回执确认 `controllerFinished`、`terminationConfirmed` 及所属目录清理，不凭 stdout、退出码、SSH close、PID、名称或新成功轮次认领旧资源。无可信凭据、离线或保存失败保留 `uncertain`，暂停派发；不恢复命令或 live grants，不通过新数据目录／实例绕过债务。

## 5. Windows 路线与完成门槛

### 当前方案与事实

Windows 目标为本地 Windows 11 x64、固定工具链和 Direct。正式目标仍是管理员明确批准设置、命令在专用非管理员身份执行，结合可验证的文件权限、网络拒绝、Job、受保护事务和恢复。桌面应用日常不提权；不提供任意 SYSTEM 命令接口，不静默选择较弱模式。

原单 restricting SID 路线被 KnownDlls／loader 阻断，仍为 NO-GO；LPAC 是独立验证的替代候选，不能将两者的通过数合并。早期[Windows 首版设计](agent-shell-sandbox-windows-v1-design.md)中的原目录实时 ACL 路线是原始提案；当前原型已推进冻结源码／依赖物化，正式对象布局和回写方案仍须根据真实项目验收确认，不能把旧提案直接视为已实现。

当前已有专用账户 LPAC 根／后代／helper 身份与 Job、有限文件和网络拒绝、Git／Node／PowerShell 7 固定工作流及独立精确恢复证据。完整依赖 SYSTEM 物化 43290 项、677 页，源码 SYSTEM 物化 883 项、14 页分别有终态；源码全量检查点后受控错误的独立 SYSTEM 恢复通过，不覆盖进程崩溃或重启。普通组合项目正常退役及磁盘页故障恢复已通过，后者仍在同一普通进程内。

最新[阶段 A 交接](agent-shell-sandbox-windows-stage-a-handoff.md)记录组合项目 SYSTEM 固定事务已启动，尚无终态和独立 OS 核验；不重复派发或读取活动对象页。真实 LPAC 完整项目类型检查、Vite 构建及前端测试仍待验收，源码模块子集成功不替代全项目。三个历史 loaded hive 槽已在重启后精确恢复并经 OS 核验；此前无持久可信页的普通测试残留仍隔离，不凭路径／时间清理。

默认 LPAC DNS 返回 87 尚不是明确权限拒绝。固定 `internetClient` 诊断已证明账户 SID、包 SID 及 RPC_UM 候选未封锁 DNS 系统服务代办；不得通过扩大 capability 掩盖绕过，也不能用零流量／超时当作拒绝。正式 broker、typed IPC、账户池及产品接入尚未完成，生产继续 `unavailable`。

A 未签收前不启动正式 B，可整理接口需求。按验收门槛安排工作，不承诺固定发布日期。崩溃／重启扩大矩阵优先在可恢复快照的专用 Windows VM 完成，最终在支持的实机复验。

Windows 文件规则必须区分现有对象快照与运行期名称变化：根 `.env.local` 只读不覆盖独立敏感规则；未来新增或替换 `.env` 不承诺持续名称保护，派发前重新识别。ACL 增量撤销保留宿主其他改动，稳定对象身份／事务未知则隔离；不得整体覆盖旧 DACL。最终文件方案需明确原目录、物化输入、产物导出及并发回写的真实边界。

## 6. 验证与交付标准

相关测试先行，最终修订按影响范围完成：

pnpm test

pnpm review:frontend

cargo fmt --manifest-path src-tauri/Cargo.toml -- --check

Windows 独立原型另外运行其 locked test、build、Clippy all-targets `-D warnings` 和 fmt；显式忽略的实机／长测试独立记录，默认 ignored 不计通过。静态检查、单元测试、组件渲染、真实 Wry、模型执行、SYSTEM 物化及 LPAC 项目运行分别说明证明范围，不使用 mock、虚假数据或为了验收放宽门禁。

每项验收记录代码修订／工作树、环境、生产入口、场景、预期与实测、证据路径、进程／资源终态和剩余缺口。历史失败不能被覆盖；新成功不能解除别轮资源。日志／截图不包含秘密、bearer 或敏感内容。没有可信终态就保留债务，不自动重放。

交付必须同时满足已声明路径／网络控制生效、日常任务可完成、授权可理解且不重复、取消／恢复无权限扩大、各工具入口能力真实及 `partial` 限制准确展示。缺环境或必要证据时保持未完成。发布、commit、tag、推送和远端配置变更另需用户明确要求；本文不授权这些操作。
