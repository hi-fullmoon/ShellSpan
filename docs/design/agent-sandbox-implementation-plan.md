# 本地 Agent 沙箱计划

状态：未实施。本计划面向本地 Direct 执行。已实现的 Linux SSH 沙箱是另一种执行环境，部署和限制见[远端沙箱部署说明](../remote-agent-sandbox.md)和[远端协议](../../protocol/agent/runtime/remote-bubblewrap.md)。现有本地权限与文件行为以[运行时协议](../../protocol/agent/runtime/file-and-script-execution.md)为准。

## 首版范围

在 Linux 容器中使用独立的项目副本。Direct 命令和结构化文件工具使用同一个副本，默认关闭网络。只有审查并确认差异后才回写宿主项目。审批模式独立于隔离策略；既有会话不会自动切换，绑定项目目录不授予写权限。宿主的现有终端和 MCP 不会因本地沙箱而获得隔离保证。

## 实施顺序

1. **定义契约。** 绑定会话、项目身份、执行环境与策略修订号；定义只读、工作区可写及显式无隔离的能力报告。执行环境无法兑现某项策略时拒绝调用。
2. **接入执行。** 制作项目副本，并限制宿主目录、套接字、网络、进程与资源。命令和文件工具沿用同一策略；子 Agent 只继承父策略与角色权限的交集。停止与超时要覆盖子进程，恢复不重放结果不确定的操作。
3. **审查与回写。** 按文件展示新增、修改和删除；在写入前检查宿主文件身份及内容版本，冲突时停止。拒绝越界、符号链接、外部硬链接和不可安全处理的文件类型。目录批量删除及自动回写不在首版范围内。
4. **验证后启用。** 在真实桌面完成导入、修改、构建测试、审查差异和回写。另验取消、冲突、异常恢复与审计失败。按平台记录实际支持能力，测试后端不能直接当作生产能力。
