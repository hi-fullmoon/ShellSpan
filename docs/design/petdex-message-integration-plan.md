# Petdex 消息气泡实施计划

依据：[确认设计](petdex-message-integration-design.md)、[协议](../../protocol/petdex/bubble.md)、[验收](petdex-message-integration-acceptance.md)。业务尚未发送消息。阶段6–11串行、各自独立用户可见会话；原会话创建下一会话，实施会话不自行续建。每阶段可构建、相关测试通过并准确交接。部署延期，不修改范围外UI，不commit/tag/push。

## 阶段6：消息契约与方案定稿

- [x] 两份文档改为AI会话/后端连接归属、三固定槽、两默认false开关。
- [x] 官方固定源码完整路由、字段上限、字符串切片、busy、寿命、fallback及无HTTP删除。
- [x] 安装版本、whoami PID/官方路径验证；两个固定键真实字段、安全UTF-8边界、同键重复写入、紧凑/带空格busy、转义后字节上限核验。
- [x] 用户提供原生截图：两槽共存、同键覆盖且另一槽不变、shellspan通用头像、普通中文标题/正文显示；关闭专注后可见。
- [x] 转义字符原生截图：英文引号、反斜杠、换行的JSON转义直接显示，确认协议限制。
- [x] 规范化截图确认可见引号/反斜杠无多余JSON转义；临时寿命5秒、busy=false后用户确认消失，已恢复0。末尾next被显示省略，不宣称完整文字可读或精确到期时间。
- [x] 寿命5秒时busy持续超过10秒且有旋转指示；同键结算false后超过10秒仍在并有等待标记，用户现场确认。
- [x] 单气泡模式仅显示最新第二槽，用户现场确认，已恢复按会话显示。
- [x] Show messages关闭后接收新请求仍无气泡，用户现场确认，已恢复true。
- [x] 显示恢复后寿命0、busy=false超过10秒仍在且带等待标记，用户确认；这是组合观察，不是无waiting的隔离计时证明，证据限制见验收。
- [x] 协议/验收及阶段7接口、阶段8规范化交接；仅已用测试键busy=false结算。

退出判断：阶段6完成。上述必需显示项已取得用户原生截图或现场观察，不以HTTP200替代；计时精度、寿命0与waiting未隔离等明确边界见验收，不据此承诺删除或自动消失。设置已恢复，全部测试槽最后为非忙碌，构建与相关测试通过；由原会话建立阶段7会话，本会话不跨阶段实施。

## 阶段7：归属与三槽调度

- [ ] 阅读领域目录说明；既有ActivityEvent/Guard扩展内部Owner/Kind，不建第二事件源。
- [ ] AI会话、SSH/SFTP后端连接；跨连接复制归目标；worker/driver代际拒绝迟到终态。
- [ ] ≤3分别展示，>3两优先对象＋第三摘要；失败>等待>完成>运行>连接中，同级稳定保留。
- [ ] 绑定代际、内容版本、绝对TTL、计数去重、分类过滤、取消；未用空槽不创建气泡。
- [ ] 随机安装标识＋固定三键，身份不外发；共用写入者、必要进程锁、最小已用槽标记。
- [ ] 直接生产回归：四归属以上、进出摘要、目标连接、同级稳定、旧事件/回执、并发取消。

退出：内部投影可构建、相关Rust回归通过；不提前开启传输或新增UI，交接类型与真实出口。

## 阶段8：模板与有限详情

- [ ] 同源双语具体阶段模板、计数、UTF-8正文200/标题96字节、应用语言。
- [ ] 两开关默认false；详情仅有限标题/文件基本名/已完成助手最终回复，不额外模型摘要。
- [ ] 成熟Markdown解析器排除代码/链接目标/HTML/图片；复用redaction，敏感字段整体模板回退。
- [ ] 按协议单行化、双引号/反斜杠可读规范化、Unicode安全裁剪、serde_json紧凑序列化，不拼raw JSON。
- [ ] 生产回归：秘密跨截断边界、已有脱敏标记、链接/代码、流式/最终回复、双语emoji、转义字节边界。

退出：内容生成/隐私回退回归与构建通过，正文不入日志，不改业务记录。

## 阶段9：传输与结算

- [ ] 复用适配器、锁/取消/兼容门禁；每槽latest-only，300ms合并，共享100ms间隔/退避。
- [ ] 独立消息诊断，旧回执不清新版本，401/429/恢复不补过期结果。
- [ ] 消息/总开关/正常退出只结算已用槽，全部共享1500ms，失败也关闭，Disabled无通信。
- [ ] 分类/详情关闭重投影，崩溃同键修正，不虚构删除/duration/全局idle。
- [ ] 生产回归：预算、部分结算、迟到回复、快速重开、代理/重定向/响应上限、误接防护；真实探针独立启用，无新替代服务。

退出：传输/关闭契约回归及构建通过，区分accepted/显示与生效配置/cleanup未确认。

- [ ] 在阶段6显示契约已经通过的基础上做真实全链显示复验，记录/恢复Petdex显示偏好；不全局清他人bubble、不停止未知进程。
