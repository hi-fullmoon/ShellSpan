# Petdex 消息气泡接入设计

状态：用户确认方案，阶段 6 定稿；当前业务仍只发送动作。真实契约见[协议](../../protocol/petdex/bubble.md)，证据与未验证项见[验收](petdex-message-integration-acceptance.md)，按[阶段 6–11](petdex-message-integration-plan.md)串行实施。范围仅 SSH、SFTP、AI，部署延期。

## 1. 归属和三个固定槽位

AI 按会话更新，不同回合复用内部会话归属。SSH/SFTP 按后端连接身份汇总，同一连接的连接过程及传输属于同一对象；跨连接复制归目标连接。不按标签页、主机显示名、路径或凭据哈希猜测身份。连接重建、AI driver/回合保留代际，迟到事件不能恢复已结束运行。

最多三个固定气泡槽位。可展示归属不超过三个时分别展示；超过三个时展示两个优先对象，第三槽摘要其余对象。摘要不能重复计算前两个对象；任务计数基于真实运行，SFTP 按批次而非文件，Connected 不算持续工作。

优先级为失败 > 等待用户 > 完成 > 运行 > 连接中。同级保持已展示对象，新对象按稳定登记次序补空位；保留对象尽量不迁槽。进入/退出摘要模式只重绑必要槽。换绑递增 bindingGeneration，内容变化递增 revision；异步发送及回执同时匹配服务代际、取消代际、槽号、绑定代际和版本，旧回执不能确认新对象。

失败/完成继续使用现有绝对 TTL（2500/1200ms），被覆盖期间照常到期，不延长、不离线补播。取消只结束对应运行；工具拒绝和内部重试不冒充 AI 回合失败。等待审批与等待回答分开，审批优先；等待消息 busy=true 用于保留提醒。没有活动/有效结果且从未使用的槽，不创建空闲气泡。

## 2. 标识和阶段 7 接口

每个用户数据目录持久化随机安装标识，外部键固定为 shellspan-<random-installation-id>-slot-1 至 slot-3，ASCII、总长不超过64字节。换绑不换键。不得发送真实 session ID、connection ID、run ID、credential hash 或其摘要。安装标识不是凭证。

多窗口共用后端写入者；若允许同目录多进程，使用成熟进程锁，无锁实例停止消息发送并有限诊断，不用随机新键规避冲突。最小持久化数据只有随机安装标识、三个槽是否已用/可能忙碌，不保存正文、任务历史或凭证。

在既有 ActivityEvent/ActivityGuard 上增加内部 ActivityOwner（AI会话/后端连接）和有限 ActivityKind（连接、上传、下载、同端复制、跨端复制、AI阶段）。权威生命周期入口提供身份与语义，不建第二套事件源。内部身份与展示详情分离，身份类型不得进入请求/诊断序列化。

投影输出包含 slot、bindingGeneration、revision、内部归属或摘要成员、阶段、计数、busy、locale、绝对截止时间。内容层转成受限请求；网络层只接收已验证请求。归属、槽位和动作使用一致活动快照，网络I/O在快照锁外进行。

## 3. 模板与另行开启的详情

petdexMessagesEnabled=false、petdexMessageDetailsEnabled=false；旧用户升级不自动开启。消息还受总开关和既有SSH/SFTP/AI分类控制。总开关关闭允许保存偏好，但不通信。详情只有总开关、消息及详情均启用才发送。

默认具体阶段白名单模板：连接、上传、下载、复制、AI准备/处理/等待审批/等待回答、完成、失败、取消、剩余任务摘要、关闭/退出。不能把已有明确阶段统一降为“正在处理”。计数为有限整数，超过99显示99+。模板双语跟随应用语言，同源有限JSON资源由Rust编译时嵌入并与前端locale校验；切语言只更新当前有效投影。正文≤200 UTF-8字节，标题≤96。

详情另行开启后只允许有限任务/会话标题、文件基本名、**已完成助手最终回复**预览，不额外调用模型生成摘要。不得取推理、流式token、工具参数/结果、用户提问、原始终端日志、完整命令参数、认证字段。文件名只从权威字段提取基本名，不发送完整路径；摘要槽不拼接隐藏对象自由文本。

详情处理顺序：

1. 从允许的结构化出口取得有界完整候选字段；缺失、未完成、取消、旧代际或超过处理上限即模板回退。不能先截断后检测而漏过秘密。
2. 复用 src-tauri/src/redaction.rs 检测候选和提取后文字；发生替换、包含既有脱敏标记或明确敏感结构时，**整个字段回退模板**，不发送部分脱敏原句。
3. 助手回复使用成熟Markdown解析器，后端推荐pulldown-cmark，阶段8按Cargo兼容版本加入。遍历解析事件，排除代码块/行内代码、HTML、图片及链接目标；自动链接地址不进入预览，只保留允许的可见文字。禁止手写Markdown解析。
4. 单行规范化：换行/Tab/控制字符转空格，移除不应显示的方向控制；ASCII双引号转可读弯引号，反斜杠转全角反斜杠，保留中文弯引号；收敛空白，空结果回退。只改展示候选，不改原业务记录。
5. 按Unicode字符边界裁剪，省略号预留字节；最终再次检测敏感内容、长度及不存在需要JSON转义的控制字符/ASCII双引号/反斜杠，使用成熟serde_json紧凑序列化。不得依赖远端截断；原始JSON字符串切片限制见协议。

隐私说明必须告知：默认仅固定状态；详情可能包含业务信息，脱敏并非绝对保证。关闭详情立即丢弃待发详情，当前有效槽回模板，旧回执不能恢复详情；已接受的内容不能撤回。正文、候选、外部键及凭证不入日志/诊断。

## 4. 传输、去重和恢复

复用PetdexAdapter、固定loopback客户端、请求锁、取消与兼容检查，不另建失控后台任务。字段仅conversation_key、agent_source、title、text、busy；agent_source=shellspan，不伪装官方客户端。不发送source_app/source_tty/source_cwd/herdr_pane_id、duration或删除字段。

每槽仅保留最新待发版本，普通更新合并300ms，失败、进入/退出等待、结算优先。动作与气泡写入共享100ms最短间隔和429退避，不挤掉动作绝对TTL。普通尝试含排队、匿名检查、凭证读取、最多一次401刷新重试，总预算1500ms。发送前/回执时检查代际与版本。

动作与消息是独立非原子请求，分别诊断；消息失败不改变业务结果或动作成功。去重包含最终正文、locale、服务代际和槽绑定。进度/token/重复事件不重发，普通探测不刷新寿命或抢最前位置。401仅令牌确有变化时重试一次。兼容失败在读取token前拒绝，禁代理/重定向、限制响应大小；匿名检查不能认证服务或消除端口切换TOCTOU。

恢复只发当前活动，不补播离线完成/失败。已用槽可能残留busy而现无活动时有限中性结算；服务代际变化可刷新当前投影。正常探测不读取他人bubble，不借镜像判断用户关闭或驱逐。bubble不支持时独立停用消息重试，服务代际变化或主动测试再试，动作继续。

## 5. 关闭、结算和退出

busy=false只结算忙碌，不代表删除/消失。0.8.0无HTTP按键删除；禁止空文字伪装清理、全局清空、全局idle或改变Petdex寿命来清自己的槽。

关闭消息/总开关/正常退出：停止新消息、取消旧发送，仅对本安装**已用槽**发送固定结算busy=false。全部槽共享一个1500ms总预算，含排队及网络，不是每槽1500ms。失败/超时也确认关闭；Disabled后不读凭证、不通信、不后台重试。退出沿用现有确认/取消流程，不扩大退出等待。

分类关闭重新投影：保留其他归属，必要时重绑；空出的已用槽中性结算，未用槽不创建。关闭期间活动继续在内存跟随生命周期，重开不补历史。崩溃/断电无法保证结算，下次明确开启后使用同三键修正，关闭期间不修复性通信。

配置回复区分实际生效配置与cleanupOutcome=notNeeded/accepted/unconfirmed。关闭已生效但结算失败仍返回关闭配置，不能抛通信错误导致store回滚开启；部分槽失败即unconfirmed，可附有限槽数，不含正文/身份。accepted也只表示请求接受，不表示气泡已删除。

## 6. 原生设置、诊断和范围

UI仅现有Petdex设置区域，沿用组件/布局；两开关、详情风险说明、固定测试文字、消息独立诊断，共用现有分类。不增加部署、点击跳转、反向命令、气泡审批或第二套分类。

测试文字复用现有三个固定槽之一，不占第四槽，不覆盖失败/等待；结束恢复最新业务投影，无业务时中性结算。超时取消预览，不能随后补发。消息诊断仅有限状态/模板、最近接收时间、槽数和结算确认，不显示正文、内部身份或token。主动操作一次Toast，后台静默；请求接受不能标为气泡已显示。说明Petdex显示开关、专注、单气泡及寿命会影响可见性。

配置IPC经过类型化适配器，Rust command/注册/TS/store/schema同步迁移。前端校验继续预编译，不运行时Ajv编译，不放宽CSP。阶段10验证双语、宽窄、焦点/键盘、Toast去重及配置并发回退。
