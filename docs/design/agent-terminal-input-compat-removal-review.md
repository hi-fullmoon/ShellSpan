## 发现及修正

1. P4仍保留`legacy-projection`枚举、前端默认值、前驱连接特判及旧客户端元数据处理。现已从Rust协议、Broker、创建/重连、运行时适配和TypeScript类型移除。当前模式只有`native-inline`与`raw`，普通未集成终端使用raw；不再给旧模式提供兼容解释。
2. 执行器仍保留非NIP描述符接收、输入确认、接受键、取消和清稿路径。现已全部移除；操作登记必须持有原生协调器，不再保留可空协调器、旧编辑器标志、旧批次状态或另一套提交锁。raw终端的源码与作业输入均在lease/PTY写入前拒绝，当前原生作业继续使用原身份及计划校验。
3. 旧路径删除后，编译器确认两层旧transport挂接包装、旧作业描述符构造/未提交清理方法及多个测试辅助已无调用者，已继续删除。仅被真实普通Shell测试使用的探针/字节编码留在测试编译边界；旧Agent输入编码从产品执行器移走，不能形成产品兼容分支。
4. 移除只服务旧逐字输入/接收中断实现的验收函数、空模块和Windows旧输入验收入口，保留新NIP回归与原始真实字节素材。Node脚本不再调用已删除测试，缺失测试不能被当成零测试通过。
5. 删除历史配置的legacy开关、旧源码重建baseline入口及旧矩阵场景。当前原生矩阵为36个版本/传输/场景组合加3个生命周期场景，共39场。历史45场入口及40场已完成/1场中断记录仍为原始证据，不改写为当前代码通过。
