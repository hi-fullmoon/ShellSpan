# Petdex 运行时边界

> 更新：2026-08-31。本文描述当前外部桌宠状态桥接的实现约束，不改变 Phase 0/3/4 的准入结论。

## 模块职责

- `src-tauri/src/petdex.rs`：Tauri 命令、生命周期、有限控制队列和连接测试协调。
- `src-tauri/src/petdex/arbiter.rs`：SSH、SFTP、AI 事件的优先级、临时状态 TTL 与并发操作归并。
- `src-tauri/src/petdex/delivery.rs`：去重、最小发送间隔、恢复探测和失败退避。
- `src-tauri/src/petdex/transport.rs`：Token 读取、固定 loopback HTTP 请求、401 轮换重试、取消与响应分类。
- `src-tauri/src/petdex/types.rs`：IPC 状态、业务事件、线协议请求和有限诊断类别。
- `src-tauri/src/petdex/tests.rs`：仲裁、投递、背压、超时、隐私和 HTTP 契约测试。

业务事件先在共享仲裁器中落地，再以最多一个 `Wake` 唤醒协调器。因此，即使容量为 16 的控制队列已满，最新业务生命周期也不会丢失；事件风暴不会生成同等规模的排队任务。

## 投递参数

| 参数 | 当前值 | 目的 |
| --- | ---: | --- |
| 最小发送间隔 | 100 ms | 限制状态切换风暴 |
| 首次失败退避 | 250 ms | 保持短暂重启的恢复速度 |
| 最大失败退避 | 60 s | 避免 Petdex 长期离线时持续轮询 |
| 首次恢复探测 | 5 s | 快速确认刚建立的状态仍可达 |
| 预热恢复探测 | 15 s | 连续成功后降低请求频率 |
| 稳定活动状态探测 | 30 s | 在传输、连接或 AI 活动期间兼顾恢复速度 |
| 稳定空闲状态探测 | 60 s | 空闲时把本地请求降到最低 |
| 手动连接测试总时限 | 2 s | 同时覆盖排队和响应等待 |

相同状态连续成功会从 5 秒逐步进入 15 秒，再进入活动 30 秒或空闲 60 秒的稳定周期。任何状态变化立即按最小发送间隔调度；可重试失败采用指数退避并封顶 60 秒；手动连接测试会清除当前退避，但仍受总时限和取消信号约束。

## 不变量

1. 功能关闭时不读 Token、不发网络请求，并取消正在等待的连接测试。
2. 目标固定为 `http://127.0.0.1:7777/state`，禁用系统代理；Token 只在 Rust 后端读取和使用。
3. 401 只在 Token 已轮换时重试一次；日志只记录有限结果类别。
4. Petdex 的失败、超时或队列饱和不得改变 SSH、SFTP、AI 的业务结果。
5. Phase 4 仍受独立证据门禁约束；这些可靠性优化不构成用户价值或资产授权证据。
